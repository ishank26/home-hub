Send a recipe home

Share a recipe link from your phone. Preview it here, then save it to your Home Hub.

Ingredients

    Method

      Open saved recipe
      Pair this phone

      On your already paired Home Hub tablet or server browser, open this page and choose Create pairing code. Enter that code on your phone within five minutes. Pairing gives this phone the same Home Hub access as your tablet.

      Set up phone sharing

      Android

      Open this page in Chrome over HTTPS. Choose Install app or Add to Home screen → Install. When viewing a recipe, tap Share and choose Home Hub Recipes. Your phone must be able to reach your Home Hub.

      iPhone

      Create a shortcut in Apple Shortcuts named Send recipe to Home Hub:

      1. In shortcut Details, turn on Show in Share Sheet. Receive URLs and Safari web pages.
      2. Add Get URLs from Input using Shortcut Input, then Get First Item from those URLs.
      3. Add URL Encode using that first URL.
      4. Add URL. Paste the address below and append the URL Encoded Text variable.
      5. Add Open URLs.

      In Safari or another recipe app, tap Share → Send recipe to Home Hub. The recipe opens here for you to preview and save.

      Use without installation

      Copy a recipe link, open this page, and paste it above. Saved recipes appear in the dashboard’s Saved library; Recipe Tracker’s separate browser library is unchanged.
